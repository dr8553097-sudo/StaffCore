# 🤝 Cómo Contribuir a StaffCore

¡Gracias por tu interés en contribuir a StaffCore! Toda ayuda es bienvenida.

---

## 🐛 Reportar un Bug

1. Ve a la sección de [Issues](https://github.com/dr8553097-sudo/StaffCore/issues/new/choose)
2. Selecciona **"🐛 Reporte de Bug"**
3. Completa el formulario con todos los detalles posibles
4. Incluye **versión del plugin**, **versión del servidor** y **logs de error**

> ⚠️ Por favor, busca primero si ya existe un issue similar antes de crear uno nuevo.

---

## ✨ Proponer una Feature

1. Ve a [Issues](https://github.com/dr8553097-sudo/StaffCore/issues/new/choose)
2. Selecciona **"✨ Solicitud de Feature"**
3. Describe el problema que resuelve y cómo te lo imaginas

---

## 🔧 Contribuir con Código

### Requisitos
- Java 21 (Temurin recomendado)
- Maven 3.8+
- Paper API 1.21.1

### Configuración del entorno
```bash
git clone https://github.com/dr8553097-sudo/StaffCore.git
cd StaffCore
mvn clean package
```

### Convenciones
- Usa el mismo estilo de código existente
- Comenta el código en **español o inglés**
- Agrega mensajes de commit descriptivos (en español está bien)
- No rompas la compatibilidad con versiones anteriores sin avisar

### Pull Requests
1. Haz un **fork** del repositorio
2. Crea una rama descriptiva: `feature/nombre-feature` o `fix/nombre-bug`
3. Haz tus cambios y commitea con mensajes claros
4. Abre un Pull Request describiendo qué cambiaste y por qué
